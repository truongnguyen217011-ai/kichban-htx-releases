# KICHBAN HTX Releases

Kho công khai này chỉ chứa bộ cài Windows, mã kiểm tra SHA-256 và manifest cập nhật đã ký số. Mã nguồn của ứng dụng không được phát hành tại đây.

Phiên bản mới nhất: **0.1.26**.

Từ 0.1.26, ứng dụng có khay hệ thống Windows thật và tự kiểm tra cập nhật định kỳ khi đang chạy. Mỗi bản cập nhật chỉ được cài sau khi chữ ký Ed25519 và SHA-256 hợp lệ, runtime cũ đã dừng an toàn, và phiên bản mới vượt qua kiểm tra sức khỏe sau khi khởi động lại.

Từ phiên bản 0.1.3, ứng dụng tự kiểm tra chữ ký, tải và cài bản cập nhật hợp lệ khi khởi động.
